# 账号 2 · 视觉风格样图

给第 2 个账号（和「算给你看」并行、分散风险）挑"脸"用的样图。两张是**同一个选题的两种皮肤**，方便直接对比。全部用代码渲染（Canvas 2D），非 AI 生图、非模板、无版权素材——这正是和满大街"代码视频/数据可视化营销号"拉开差距的点。

竖屏 1080×1920，适配抖音。

| 风格 | 预览图 | 代码 | 一句话 | 结论 |
|---|---|---|---|---|
| D · 印刷/Riso 版式 | [preview/D-印刷.jpg](preview/D-印刷.jpg) | [D-riso/scene.js](D-riso/scene.js) | 暖纸 + 墨 + 朱红跳色，实色块 + 强排版 + 真·半调网点 + 人生格子数据母题 | **← 选定（乙路线）** |
| B · 水墨国风 | [preview/B-水墨.jpg](preview/B-水墨.jpg) | [B-shuimo/scene.js](B-shuimo/scene.js) | 宣纸 + 淡墨山月 + 宋体 + 红印 | 否：矢量假装水墨，无笔触纹理，"颗粒度不够、怪" |
| C · 绘本插画 | [preview/C-绘本.jpg](preview/C-绘本.jpg) | [C-huiben/scene.js](C-huiben/scene.js) | 暖色扁平插画 | 否：小人像线框草图，不是插画，太糙 |

> A（纸上手账风）用户否掉（"看过类似的，像屎一样"）。
>
> **为什么是 D：** B / C 想用代码仿"手绘/纹理"，那是代码（Canvas 矢量）最不擅长的，结果都是"矢量很干净却在假装手绘"的别扭感，不是加点颗粒能救的——是工具天花板。用户已排除"甲路线（AI 生图，画面上限高但要人工操作、成本高）"，锁定"乙路线：全代码、Kiro 全自动"。
> 乙路线的正确打法 = 不装手绘，玩代码真正的强项：**实色块 + 极强排版 + 2–3 色 + 程序化的半调网点/套印错位（真颗粒）+ 数据可视化母题**。D 就是这条路，第一版底部排版撞车，修布局后达标。

两张共用的招牌元素（反营销号）：
- 大数字是**算出来 / 标了来源**的（图里底部那行小字）
- 预留了结尾"**把数字甩回给观众**"的位置（B 的"你已经用掉了几分之几？"）

渲染命令（在仓库根目录）：

```sh
node engine/render.mjs account2-samples/B-shuimo --preview 0 --scale 1
node engine/render.mjs account2-samples/C-huiben --preview 0 --scale 1
```
