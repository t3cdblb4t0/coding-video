# 账号 2 · 视觉风格样图

给第 2 个账号（和「算给你看」并行、分散风险）挑"脸"用的样图。两张是**同一个选题的两种皮肤**，方便直接对比。全部用代码渲染（Canvas 2D），非 AI 生图、非模板、无版权素材——这正是和满大街"代码视频/数据可视化营销号"拉开差距的点。

竖屏 1080×1920，适配抖音。

两张共用的招牌元素（反营销号）：
- 大数字是**算出来 / 标了来源**的（图里底部那行小字）
- 预留了结尾"**把数字甩回给观众**"的位置（B 的"你已经用掉了几分之几？"）

渲染命令（在仓库根目录）：

```sh
node engine/render.mjs account2-samples/B-shuimo --preview 0 --scale 1
node engine/render.mjs account2-samples/C-huiben --preview 0 --scale 1
```
