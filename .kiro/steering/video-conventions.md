# 算给你看 · 制作约定

- **画幅**：从第 02 期起，母片一律横屏 16:9（1920×1080，30 fps，用户要求）。第 01 期保持竖屏 9:16，不改。
- **抖音竖版**（第 04 期起试验）：另出 1080×1920 竖版包装：上方常驻大标题、中间 16:9 画面、下方放大的双语字幕（参考 `videos/005-regression-vertical`）。场景要导出 `OPTS`（关掉内部字幕和台标）、`getCaptions()`、`actAt()`。结果：第 04 期竖版 2 秒跳出 36.52%（第 02 期 45.28%、第 03 期 40.94%），方向对但幅度不大，抖音继续发竖版。
  - 横版画面里缩到竖版后小于约 36px、又很重要的字（开头的问题、片尾的评论问题和下期预告），在竖版里补成字幕；开头的问题从第 0 帧就显示，第一帧下方不留空。
- **时长与价值**（用户决定，第 05 期起）：时长可以长（2 分钟左右没问题），重点是把内容做好、给观众带来真正有用的东西。不为了完播率砍内容。但因为第 02–04 期完播率只有约 0.5%：结论和最精彩的模拟画面要放在前面；关注理由、评论问题不能只放片尾（开头、发布文案、置顶评论都要有）。
- **"有用"的标准**：每期除了"原来如此"，还要给观众一个能带走的方法或判断标准（例如第 05 期：看到"做了 X 之后就变好了"，先问"不做 X 会不会也变好"）。
- **音频**：不需要做配乐，用户后期自己配。场景不写 `audio()`，输出只有画面的 MP4。各段落仍从 100 BPM 的小节线开始（1 小节 = 2.4 秒），方便卡点。
- **形式**：不配音，中英双语字幕；先讲清"为什么"，再给反转。
- **可信度**：随机种子提前固定、结果不挑；片中数字一律从模拟结果读取；事实和实测结果写进该期的 `分镜.md`，供发布前核对。只用来画图的样本要和计数的实验分开种子。
  - 画面上的算式要对得上：差值、拆分都用**四舍五入后**的数来算（第 05 期的 `luck()`、`gain()`：38.8 → 48.8 显示 +10.0，不显示精确值算出的 +10.1）。
  - 事先定好的规则挑出了"反例"时（第 05 期选出的示范学员第二次反而更好），不另挑一个"听话"的，改用整组平均，并在 `分镜.md` 里写明。
  - 标题、封面里的百分比要说清是谁的百分比（第 05 期竖版标题从"谁也不骂，84% 照样变好"改成"最差的人不挨骂，84% 照样变好"）。
- **不留空屏**：每段一开始就要有画面内容，不能只有标题等 3 秒（第 05 期自检发现两处，改成先出空卡片、先出 1,000 个点）。
- **流程**：先在 `分镜.md` 写分镜，再分模块实现，用 `--preview` 抽帧检查，最后完整渲染、用 `engine/inspect.mjs` 验证、用 `--cover` 导出封面。竖版字幕用 `engine/caption-check.mjs` 检查换行。
- **数据**：用户发来的后台数据记进 `运营/数据复盘.md`（原始数据表 + 判断 + 下次对比哪个数）。
- **开头 5 秒**（第 03 期数据：2 秒跳出 40.75%，5 秒内走掉 67.6%，平均只看 8 秒）：
  - 第一帧必须完整，不许渐入。开场就是封面同款构图：带数字的反常识结论 + 动起来的画面。
  - 2 秒内给出结论，再用一个关于观众本人的问题留人；不要把答案拖到 20 秒以后。
  - 互动问题放进开头、发布文案和置顶评论（每期在 `运营/数据复盘.md` 写好）；只放结尾几乎没人看到。
- **文案/涨粉**（第 03 期起）：时长 1–2 分钟，每段只讲一件事；关键字号 ≥36px、核心数字 ≥110px；关注理由具体化。
- **方向**（第 04 期起，用户要求）：内容往**心理、哲学**方向靠。题目仍用代码真实计算，但最后落到一个关于人、关于选择的问题上。引申的观点要和数学结论分开标注（"想一想"卡片 + 片尾说明"是我们的引申"）。
- **系列风格**（第 04 期起固定，组件在 `engine/brand.js`）：
  - 三段式「**问 → 算 → 想**」，右上角 `drawActs` 进度条常驻；左上角 `drawBadge` 台标「算给你看 · NN」。
  - 每个大模拟开始时用 `drawSimTag` 弹出「▶ 模拟 N 次」。
  - 收尾固定栏目「**算完了，想一想**」（`drawThinkCard`）：思源宋体 + 暖色纸面，最后一句是给观众的观点题。
  - 评论区问题用观点题（人人都能答、能引出理由），不只问"你选哪个"。
  - 每期实现 `cover()`，用 `drawCover` 出 16:9 / 4:3 / 3:4 三张封面；开场第一帧和封面用同一构图、同一句话。
- **选题顺序**：01 扔针算 π → 02 三门问题 → 03 生日问题 → 04 随机游走 → 05 回归均值（卡尼曼与飞行教官）→ **06 幸存者偏差**（第 05 期片尾已预告"成功人士都在讲的经验，可能是幸存者的错觉"；动手前先核实沃尔德与二战轰炸机弹孔的故事，网上流传的版本有不少夸张）。
