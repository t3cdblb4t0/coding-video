第 05 期发布前后整理（10-28）。目的：找出前 5 期涨不了粉的原因，定第 06 期起的做法。

## 爆款都做到、我们没做到的

| | 爆款 | 我们（第 01–05 期） |
|---|---|---|
| 形式 | 横屏 16:9、没有人声、2–5 分钟 | 一样。**不配音、可以长，都不是问题** |
| 开头 | 先"演"一个小场景或小谜题，让观众跟着猜，末尾一句对"你"说；6–24 秒后才出片名 | 第 04、05 期第 0 帧就给答案；第 05 期接着近 20 秒是名片和引文卡，第 24 秒才开始模拟 |
| 字幕 | 每句 13–21 字，最长 18–28 字；每分钟 140–240 字；26–42% 的时间不放字幕，让画面自己演 | 第 05 期每分钟 297 字，平均 20 字、最长 35 字，84% 的时间有字 |
| 一句一动作 | 字幕说什么，屏上就真的发生什么；没有配着静止画面的句子 | 名片、引文卡、想一想卡片都是静止的字 |
| 画面 | 一次只亮一样东西；字从模糊到清楚"显影"出来；不弹跳、不从屏外滑入；靠溶解、闪白、推近换镜头 | 一屏多个框和标签；元素弹出来（outBack） |
| 母题 | 全片一个比喻或图形贯穿始终，结尾回到开头的画面 | 每段换一种图，结尾是卡片和片尾字 |
| 常驻元素 | 左上小章节标；角上一个会"报数"的仪表 | 台标 + 进度条（不报数） |
| 声音 | 画面卡音乐乐句，或代码合成：出字、计数都有声，结论前静音 2–3 秒 | 没有声音，配乐后加，跟画面对不上 |
| 选题 | B 站前 100：天花板最高的是"金句式思维"片（如《银牌的眼泪》）；平均最高的是认知心理；数学概率最多也最卷；100 条里 70 条标题带数字 | 前 4 期是数学概率经典题（三门、生日……），是最挤的一类 |

## 第 06 期起的做法

1. **先演，后命名**：开头是一个能让观众跟着猜的小场景，第一句完整出现在第 0 帧，末尾一句问"你"；片名卡放在 6–15 秒。答案不放在开头。
2. **字幕**：每句 ≤ 18 字，每分钟 140–240 字，留出没有字幕、让模拟自己跑的段落。用 `node engine/caption-density.mjs videos/<期>` 量出来，写进分镜。
3. **画面语法**：`engine/film.js`（逐字显影、闪白、尘埃、片名卡、章节标、分母表）。
4. **母题 + 回扣**：每期定一个看得见的东西贯穿全片（第 06 期：弹孔和没回来的飞机），结尾回到开场画面。
5. **音效轨**：`engine/sfx.js`，每个画面事件都有声音；另出 WAV，用户在剪映里叠音乐。
6. **事实带出处**：年份、人名、原题直接上屏；传说标"据说"，示意标"示意"；片尾放文献线索。
7. **选题**：认知心理优先，标题里放一个具体数字。
8. **只做横版**：爆款本来就是横屏；第 05 期发的横版，2 秒跳出和第 04 期竖版一样（36.85% 对 36.68%），用户也觉得竖版观感不好。

## 迭代方式

- 每期先做开头约 30–45 秒的样片，用户看过再做全片（开头决定大部分人走不走）。
- 第 06 期是一次整体改版；之后每期只改一个大变量。
- 每期固定记 4 个数：平均播放时长、2 秒跳出、5 秒完播、涨粉（再加收藏）。写进 [数据复盘.md](数据复盘.md)。
