# 老汽修站场景白模 + 生图提示词（第1–10集）

`output/` 里的图都是从**同一个 3D 模型**渲染出来的。门、窗、家具、车辆的位置在所有机位里完全一致，16:9，1920×1080。

白模只负责锁定**构图和布局**，颜色只是材质分区，不是最终效果。把白模上传给 GPT，配上下面的提示词，转成 3D 国漫风格。

## 用法

- **M 系列（母版）**：上传一张白模，粘贴对应的整段提示词。
- **E 系列（状态变化）**：上传两张图。第 1 张是**已经生成好的对应成品图**，第 2 张是 **E 白模**，再粘贴对应提示词。这样画风和细节跟着成品图走，只改有变化的地方。
- `P0_总平面俯视图` 是给团队看的平面布局，不用拿去生图。
- 第 10 集的高中校门是独立场景，没有白模，直接用文末的 M11 / E7 提示词。
- 场景布局、时间线、状态表等设计依据见 [场景设计方案.md](场景设计方案.md)。
