# 《修车铺里走出的千亿重工双雄》第1–10集 场景设计方案

原则：**剧本一个字不改，场景去满足剧本**。下面所有布局都已经做进 3D 白模（`output/` 里的图），白模和本文档一致。

## 一、时间线（决定场景状态）

| 故事时间 | 场次 | 依据 |
|---|---|---|
| D1 下午（下葬当天） | 1-1 → 2-1 → 3-1 → 4-1，时间连续 | 每集紧接上一集 |
| D1 夜 | 5-1 → 6-1 → 7-1，时间连续 | 5-1"白天二叔二婶的咒骂" |
| D2 清晨 / 白天 | 8-1、8-2 | 8-2"昨晚撕碎的奖状" |
| 几天后 | 9-1 | 剧本原文 |
| 9 月初开学日 | 10-1 | 新生报到 |

6-1"下个月就要去报到" + 10-1 开学 → D1 是 **8 月盛夏**：屋里电风扇、凉席，外景树是绿的。

## 二、汽修站总布局（全剧不改）

```
【北】
后院 · 车间：修理地沟｜东墙工具墙（挂重型大扳手）｜轮胎｜机油桶
     ↑ 堂屋后门                      ↑ 侧车道（货车从这里开进车间）
平房一排：[西屋·陆宇卧室] [堂屋] [东屋·陆野卧室] [侧车道口·蓝灰色大卷帘门]
     ↓ 堂屋墨绿色铁皮门（朝南，正对大院）
大院（水泥地）：西侧大杨树+轮胎堆｜东侧红色三轮+报废面包车｜墙根三个花圈
     ↓
院门：蓝色双开大铁门（西扇向内开、东扇关）+ 红色招牌"陆记汽修 补胎 加水"
     ↓
国道
【南】
```

| 元素 | 对应剧本 |
|---|---|
| 院门宽 4 米 | 9-1 货车开进来；4-1"逃出汽修站大门" |
| 大院水泥地 | 4-1 扳手"掉在水泥地上" |
| 铁皮门朝南正对大院，门两侧有窗 | 1-1 打量大院；4-1 陆宇"站在堂屋门口" |
| 门前铺旧钢板、散落零件 | 1-1"嘈杂的脚步声" |
| 侧车道大卷帘门 = "后院的卷帘门" | 4-1 虎子带人冲出来 |
| 后院车间 + 修理地沟 | 9-1；3-1 重型扳手的来源、"嗞啦"声的方向 |
| 一明两暗，卧室门开向堂屋 | 6-1 陆野出门取通知书 |

**4-1 方位验证**：陆野面朝南逼二叔 → 虎子从东北角卷帘门冲出，站到陆野身后（北侧）→ 二叔二婶往南逃出院门 → 陆野"转过身"朝北，正好看见堂屋门口的陆宇。

## 三、堂屋（1-1、2-1、3-1、8-1）

```
【北墙】 配件箱·机油桶 ··· 供桌（两张遗像）··· 后门（向外开）→ 后院
                     蒲团A  火盆  蒲团B
【西墙】 门→陆宇卧室、挂历、工作服     【东墙】 旧沙发 + 玻璃茶几（靠后门）
                                         门→陆野卧室
              中间空地约 3 米（表演区）
【南墙】 窗 ｜ 西扇（插死，关）｜ 东扇（向内开）｜ 窗
              ↑ 陆野蹲这里      ↑ 二叔二婶从这里进
```

- 门槛到蒲团约 3 米，蒲团到供桌约 1.2 米，门槛高 10cm。
- **1-1**：陆宇跪蒲团 A，背对门 →"缓缓转头"成立。陆野蹲西扇内侧，不挡门。二叔二婶站东侧，陆野沿西侧冲过去扶哥哥。
- **2-1 结尾（最大穿帮风险）**：剧本没写陆野离开，但 3-1 他从后院进来。陆德海卷袖子说"敬酒不吃吃罚酒"时，让陆野从东北角后门退出画面；3-1 开头"啪"的镜头里不能有陆野。
- **3-1**：众人视线统一看向东北后门。茶几就在后门旁，陆野进门顺手砸。陆德海背对铁皮门站，4-1 才能"退到大院"。
- **8-1**：铁皮门关着，晨光只从南窗进；火盆在两个蒲团中间，磕头磕在水泥地上不受影响。

## 四、陆宇卧室（5-1、6-1、7-1、8-2）

- 北墙整面奖状（30 张以上），窄书桌靠墙；最大一张贴在书桌正上方约 2 米高（坐着够不到，站上椅子正好够到）。
- 木头硬椅，不带轮子；书桌抽屉里放防风打火机。
- 西墙单人床 + 凉席，床尾小凳上放电风扇；西墙小窗挂碎花窗帘。
- 门边（东墙）矮柜：陆野"慌忙放下碗"放这里。
- 唯一光源是绿色铁皮台灯；书桌前留空地（瘫坐、纸灰落地）。

## 五、车间（9-1）

修理地沟带台阶；门高 4 米以上能停大货车；东墙工具墙挂着 3-1 那把重型大扳手（几天后已挂回）；入口两侧红砖门柱（陆宇躲在门柱后）；背景学徒必须是 4-1 那 3 个人。

## 六、县重点高中门口（10-1）

主牌匾"清河县第一中学" + 门柱竖牌"省级重点中学"（同时满足 10-1"县重点"和 5-1"省重点"）；横幅"热烈欢迎新同学"不写年份；校门对面马路边能停三轮；大部分家长往外走，陆宇才能"逆着人流"。

## 八、生图防穿帮要点

1. 同一场景的状态变化**用"成品图 + E 白模"修改**，不要重新生成。
2. 剪在一起的相邻镜头里都能看到的东西必须一致（主色、关键物体数量、左右位置、门窗结构、剧情道具、文字）；杂物摆法、墙皮油渍形状可以放宽。
3. 生成后检查：铁皮门墨绿色 + 白挽联；卷帘门蓝灰色；堂屋 2 个蒲团、火盆在中间；后门在北墙右端；车间工具墙上有大扳手；招牌文字没写错。
